Frequently asked questions

Last updated 2026-05-24

Before you ask — Blue Client is in free public beta. Many features are still being built and some things don't work yet. For anything not covered here, join the Discord.
General

What is Blue Client?

Blue Client is a Minecraft 1.8.9 client focused on 1.8 PvP. It adds HUD customization, quality-of-life mods, and cosmetics on top of a 1.8 base.

Unlike most custom clients (Lunar, Badlion), Blue Client is not a Java mod loaded on top of the Minecraft jar. The underlying engine is written in Rust from scratch.

Why 1.8.9 only?

1.8 combat is the PvP community standard. We're focusing on that. Other versions are not on the roadmap right now.

Is it free?

Yes, the beta is completely free for everyone. Some features may become paid in the future, but if that happens it'll be opt-in and announced in the Discord first — anything you can already use for free stays free.

Is this a cheat client / ghost client?

No. Blue Client has no combat assistance, aim bots, reach hacks, or similar features. It's a cosmetic / HUD / QoL client in the same category as Lunar or Badlion.

There is currently a known compatibility issue with Grim AC that causes Simulation false positives during sword block-hit cycles and some max-reach attacks. We're actively investigating it. See the known issues on the home page.

Beta access

How do I get beta access?

Join the Discord — downloads are posted there for anyone to grab, no invite needed.

Can I share the build with friends?

Please point them to the Discord instead of passing the file around directly — that way they get the current build, checksums, and the known-issues list, and we can reach them if something changes.

Can my account get banned for using this?

Blue Client doesn't include any features that break Minecraft's EULA or a typical server's rules. We treat it like any cosmetic / HUD client.

That said, servers decide their own rules. If a server bans all third-party clients, or if the ongoing Grim AC false-positive affects you, that's a risk you take by using a beta build. We don't take responsibility for bans.

Technical

Why Rust? Is the .exe going to be flagged as a virus?

Rust is the language the engine is written in. The build is a normal compiled binary — no scripts, no obfuscation, no DLL injection.

Because we're not a large signed publisher yet, Windows SmartScreen may show a warning on first run (it does this for most small-dev binaries). If that makes you uncomfortable, don't install.

Does it run on macOS / Linux?

Windows and Linux builds are available now. macOS isn't supported yet — it's a possible future target, not something we currently build or test.

System requirements?

Lower than Java clients in most cases. A GPU that supports Vulkan or DX12 (any laptop from the last ~8 years) and roughly 1 GB of RAM available. No exact numbers yet.

Can I use Forge / OptiFine mods?

No. Blue Client isn't a Java mod, so Java-ecosystem mods (Forge, Fabric, OptiFine) don't apply. Features from those ecosystems will be built natively as first-party mods, or not at all.

Does it support single-player / LAN?

Yes. Single-player boots a local PaperSpigot 1.8.8 server in the background (Java 8 is auto-downloaded if you don't have it) and connects to it over localhost — there's no built-in world generator or integrated server of its own. LAN play isn't supported yet.

Does it support Microsoft / Mojang accounts?

Microsoft accounts only (standard OAuth Device Code Flow). Mojang accounts have been migrated by Microsoft since 2023.

Which servers does it work on?

Any vanilla-compatible 1.8 (protocol 47) server. ViaVersion-backed servers work in principle but are not a primary test target.

Servers running Grim AC with strict thresholds may show Simulation false positives — see the known issues.

Development

Is it open source?

No. Blue Client is closed source.

Can I request a mod / feature?

Yes — the Discord has a channel for feature requests. Priority goes to things with broad PvP utility first.

I found a bug. Where do I report it?

Use the /bug command in #bug-report on the Discord — it opens a private thread just for you and the moderators. Include what you were doing, what happened, the server you were on, and the build version, and attach the crash log if the client crashed (saved to ~/.blue/crashes/). Screenshots / video help a lot.

When will 1.0 / a stable release happen?

No ETA. The free public beta is out now, but a polished 1.0 is a ways off — we'd rather ship when it's actually stable than promise a date.

Is this affiliated with Mojang or Microsoft?

No. Blue Client is an independent project. Minecraft is a trademark of Mojang Studios.
