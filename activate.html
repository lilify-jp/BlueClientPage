Step-by-step

Activate in 3 steps

Most buyers are done in under two minutes. Open the email, join Discord, paste the code — that's the whole flow.

  1. Check your inbox for the redemption code

    The email subject is "Your Blue Public redemption code". It contains a single code in the format BLUE-XXXX-XXXX-XXXX (four-character groups, 12 characters total). If you don't see it within a minute or two, check your spam / promotions folder — the email is sent through Resend and occasionally gets filtered.

  2. Join the Blue Public Discord

    The Beta Access role lives on Discord — you'll need to be in the server before the bot can grant it.

    Join the Discord

  3. Run /redeem <your code> in any channel

    Type /redeem in any text channel, then paste the code from your email. The reply is ephemeral — only you can see it, so the code never leaks publicly.

    On success: the Beta Access role is added to your account instantly, and the #beta-downloads channel unlocks. Grab the latest build from there.

Heads-up

Did you link Discord at checkout?

Auto-grant path — Ko-fi lets you connect your Discord account during checkout. If you did, the Beta Access role is granted to you automatically the moment the purchase clears, before the email even lands. You'll still receive the redemption code by email; keep it. It's the only way to transfer the entitlement to a different Discord account later if you ever need to.
Troubleshooting

If something doesn't work

No email after 10 minutes

Check spam / promotions, then search your inbox for "Blue Public". If still missing, open a ticket in #beta-redeem on Discord with the email address you used at Ko-fi checkout — an admin will reissue the code.

"That code is not valid"

Double-check that you copied all four groups (12 characters) without surrounding spaces, and that the prefix BLUE- is included. Codes are case-insensitive but hyphens are required.

"That code has already been redeemed"

Each code can be used exactly once. If you've redeemed and lost access (e.g. you left the Discord), open a ticket in #beta-redeem with your Ko-fi order ID — we can re-grant the role without minting a new code.

"Redemption is temporarily unavailable"

The license server is briefly unreachable. Wait a minute and try again. If it persists for more than 10 minutes, ping a staff member on Discord.

I lost the email and the order ID

Ko-fi keeps a copy of every purchase under your account. Sign in at ko-fi.com, open your purchase history, and the order details will be there.

I want a refund

See the refund policy in the EULA, section 4. Lifetime Beta Access is non-refundable except as required by law, with a defined carve-out for documented technical defects. Refund requests go in #beta-redeem.
