What works today

Everything below is running right now. The list is short — we're being honest.

Online login

Microsoft account authentication via Device Code Flow. No offline-only accounts.

Multiplayer ready

Connects to any vanilla-compatible 1.8.9 server. AES/CFB8 encryption + zlib compression.

Native performance

No JVM. Rust + wgpu rendering, tokio networking. Faster boot, lower RAM than Java clients.

Custom launcher

Tauri-based cross-platform launcher. Account management and version selection.

HUD editor

Drag-to-place HUD elements. Positions saved per profile.

Resource packs

Standard 1.8.9 resource packs work. Apply and manage from the in-game menu.

Technical angle

Why rewrite in Rust?

Most 1.8 custom clients are Java mods loaded on top of the original jar. That means a JVM, mod-loader overhead, and inherited memory footprint.

This client ships a Rust engine instead — rendering, physics, networking, protocol, all rewritten from scratch. The payoff is lower memory use and faster cold start. The cost is everything has to be reimplemented one method at a time.

That's why the beta is closed and the feature list is short. It's also why each feature that ships is native, not emulated.

Transparency

Known issues

We're keeping this page honest. Here's what's broken right now.

Anti-cheat

Grim AC flags during PvP block-hit

Vanilla-physics-equivalent client movement still produces Simulation flags on strict Grim servers during sprint toggles, W-tap, and sword-block PvP. Root cause unidentified. If your server runs Grim with tight thresholds, expect false positives. Zombie/mob combat is unaffected.

Scope

No single-player

There's no world generation, no integrated server, no local save. Multiplayer only. This is a scope decision, not a bug — the client is aimed at servers.

Incomplete

Rendering gaps

Some visuals are missing or placeholder: water flow direction, signs text rendering, banner patterns, piston animation, a few entity models. Functional but rough.

Mods

Most listed mods aren't implemented

The roadmap section is aspirational. Today there are 14 working mods out of ~150 planned. We'll ship more over time, but don't install expecting Lunar/Badlion parity.
